# ScreenRuler Pro v2.0.0 - Major Enhancement Release

## 🎉 Major Release: Enhanced Interactivity & User Experience

This major release brings significant enhancements to ScreenRuler Pro, including mode visibility toggles, position preservation, enhanced window management, and comprehensive text annotation capabilities.

---

## ✨ What's New in v2.0.0

### 🎯 Mode Visibility Toggle System
- **Click to Show/Hide**: Each measurement mode can now be toggled on/off
  - Click 📏 Ruler icon to toggle ruler visibility
  - Click ¼ Fractions icon to toggle fractions visibility
  - Click ∠ Angle icon to toggle angle visibility
  - Click ⬟ Polygon icon to toggle polygon visibility
- **Smart Behavior**: Click different mode to switch, click same mode to hide
- **Visual Indicators**:
  - **Blue** = Active and visible (current mode shown)
  - **Gray** = Inactive but available
  - **Dimmed gray** = Hidden from view

### 📍 Position Preservation
- **Maintains Position**: When switching between modes, position is preserved
  - Switch from ruler to angle → angle appears at ruler's center
  - Switch from angle to polygon → polygon appears at angle's center
  - Switch back to ruler → ruler appears at previous center
- **No More Resets**: Modes remember where they were positioned
- **Smooth Transitions**: Seamless switching between measurement types

### 📐 Enhanced Polygon Mode
- **Sides Preservation**: Changing polygon sides keeps the center position
  - Adjust from 3 to 20 sides without repositioning
  - Polygon shape updates in place
  - No jumping or resetting to screen center

### 🪟 Improved Window Management
- **Toolbar Close Button**: Now exits entire application (not just toolbar)
  - Consistent behavior with user expectations
  - Closes ruler, text, and all windows
- **Standard Title Bars**: Both toolbar and control panel use native Windows chrome
  - Better OS integration
  - Proper taskbar behavior
  - 95% transparency for modern look
  - Native minimize/maximize/close buttons
- **Minimize to Tray**: New option in multiple locations
  - File menu: "Minimize to Tray"
  - Right-click menu: "🔻 Minimize to Tray"
  - Minimizes entire app to system tray icon

### ✏️ Text Selection & Management
- **Click to Select**: Click any text object to select it
  - Gold border appears around selected text (#FFD700)
  - Dashed border pattern (5-3) with 3px thickness
- **Delete Selected**: Press Delete or Backspace to remove selected text
- **Toggle Selection**: Click selected text again to deselect
- **Clear Selection**: Click anywhere else to deselect
- **Visual Feedback**: Clear indication of which text is selected

### 🎯 Centered Default Positions
- **Screen Center Start**: All modes now start at screen center
  - Ruler: Centered horizontally and vertically
  - Angle: Arms positioned from center point
  - Polygon: Shape centered on screen
  - Text: New text starts at center
- **Multi-Monitor Support**: Works correctly across multiple displays
- **Virtual Desktop**: Calculates center of entire desktop area

### 📝 Text Annotation System
- **Text Mode Toggle**: Click the A button in toolbar to activate text mode
- **Add Custom Text**: Enter text in input field and click "Add"
- **Independent Movement**: Drag text objects anywhere on screen
- **Multiple Text Objects**: Add as many annotations as needed
- **Enhanced Cursor**: Cursor changes to "fleur" (move) when hovering over text

### 🎨 Text Formatting Toolbar
When text mode is active, the toolbar expands with formatting options:
- **Font Size**: Choose from 8pt to 72pt (default: 12pt)
- **Font Family**: Select from Arial, Times New Roman, Courier New, Verdana, Tahoma
- **Bold/Italic/Underline**: Styled B/I/U buttons for quick formatting
- **Text Outline**: Toggle outline for better visibility
- **Visibility Control**: Show/Hide all text with eye button (👁)
- **Clear All**: Remove all text annotations with trash button (🗑)
- **Real-time Updates**: All changes apply instantly to existing text

### 🎭 Enhanced Theme Support
- **Black Theme**: Adjusted to #0A0A0A (dark gray) for visibility
- **White Theme**: Adjusted to #F5F5F5 (light gray) for visibility
- Both ruler and text remain visible in all themes

### 🖥️ User Interface Improvements
- **Dynamic Toolbar**: Automatically resizes when text mode is active (155px → 245px)
- **Wider Layout**: Default width increased to 490px for better spacing
- **View Menu**: New "Screen Text" option with checkmark indicator
- **Consistent Styling**: All windows match Arc theme colors (#5294e2 blue)

### 🌍 Multilanguage Support
- Full UTF-8 encoding support for any language
- Display text in your preferred language

## 📋 How to Use Text Annotations

1. **Activate Text Mode**: Click the A/T button in the toolbar (shortcut: Ctrl+T)
2. **Enter Your Text**: Type in the text input field
3. **Add to Screen**: Click the "Add" button
4. **Position Text**: Drag the text to your desired location
5. **Format Text**: Use the formatting toolbar to customize appearance
6. **Toggle Visibility**: Click the eye icon (👁) to show/hide all text
7. **Clear All**: Click the trash icon (🗑) to remove all text annotations

## 🚀 Installation

### Option 1: Download Pre-built Executable
1. Download `ScreenRuler_Pro_v2.0.0.exe` from the [releases page](https://github.com/Dinuka0001/ScreenRuler-Pro/releases)
2. Run the executable - no installation required!

### Option 2: Build from Source
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python ScreenRuler_pro.py`
4. Or build: `python -m PyInstaller ProRuler.spec`
